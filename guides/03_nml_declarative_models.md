# 📐 Guide 03: The Secret Blueprint Language (`.nml`)

> *Imagine you're building a LEGO spaceship. You don't build it while flying it! First, you have a blueprint showing all the laser cannons, engines, and cockpits. That blueprint is what `.nml` (Neural Markup Language) is for.*

---

## 🏗️ Why Do We Need a Separate Blueprint?

In regular programming, people mix everything together: the robot's design, the training loop, and the graphics card settings. It looks like a messy room with toys, clothes, and pizza boxes everywhere.

TensorLoom fixes this with **Separation of Concerns**:
- **`.nml` files**: Pure, clean architectural blueprints (like LEGO instruction manuals).
- **`.tl` files**: The interactive control room that builds the robot and tests it.

---

## 🧩 The 4 Magic Blocks of an NML File

Every `.nml` blueprint is made of 4 simple blocks:

```
┌─────────────────────────────────────────────────────────────┐
│ 1. @model Name:     ➔ What is the robot called?             │
│ 2. @config:         ➔ What power dials does it have?        │
│ 3. @layers:         ➔ What parts (eyes, gears) are inside?  │
│ 4. @forward(input): ➔ How does information travel through?  │
└─────────────────────────────────────────────────────────────┘
```

Let's look at an actual Transformer Attention Block in `transformer.nml`:

```
@model TransformerBlock:
    // Block 1: The Settings Dial
    @config:
        d_model = 512          // How wide is the thought stream?
        n_heads = 8            // How many eyes are looking at the words?
        dropout_rate = 0.1     // Randomly turn off 10% of gears so it doesn't overthink

    // Block 2: The Physical Parts Inside
    @layers:
        attention = MultiHeadAttention(d_model, n_heads)
        norm1     = LayerNorm(d_model)
        norm2     = LayerNorm(d_model)
        ff        = Linear(d_model, d_model)
        dropout   = Dropout(dropout_rate)

    // Block 3: How Thoughts Flow
    @forward(x):
        let residual = x                           // Remember the original thought
        x = norm1(x)                               // Calm the numbers down
        x = residual + dropout(attention(x))       // Add attention superpowers
        let residual2 = x                          // Remember again
        x = norm2(x)                               // Calm down again
        x = residual2 + dropout(ff(x))             // Final reasoning step
        return x                                   // Return the smart answer!
```

## 🪄 The 3 Behind-The-Scenes Magic Tricks

When TensorLoom reads your `.nml` blueprint, it does **3 genius transformations** so you never have to write repetitive Python code again:

### 1. Magic Trick #1: Dials Become Configurable Knobs
The compiler turns everything in `@config` into overridable settings on your Python class:

```python
# Generated by compiler:
def __init__(self, d_model=512, n_heads=8, dropout_rate=0.1):
```

This means someone can buy your blueprint and change the size with one line:
```python
# A pocket-sized mini robot:
pocket_bot = TransformerBlock(d_model=64, n_heads=2)

# A giant super-computer robot:
giant_bot = TransformerBlock(d_model=2048, n_heads=32)
```

---

### 2. Magic Trick #2: The Auto-Wire Connector (`self.`)
In normal Python, you have to write `self.` fifty times: `self.d_model`, `self.n_heads`, `self.dropout`. It hurts your fingers!

In TensorLoom, you just write `d_model`, and the compiler automatically wires it up to `self.d_model`:
```
You wrote:     MultiHeadAttention(d_model, n_heads)
Compiler emitted: nn.MultiheadAttention(self.d_model, self.n_heads)
```

---

### 3. Magic Trick #3: Auto-Calling Layers
When you write `x = norm1(x)` in `@forward`, TensorLoom knows that `norm1` is one of your declared layers, so it automatically prefixes it: `x = self.norm1(x)`.

---

## 🎯 Why This Makes You a 10x Faster AI Engineer

- **Zero Typos**: No more forgetting `self.` or messing up constructor arguments.
- **100% Reusable**: You can share `transformer.nml` with any team or project, and they can customize it without touching the internal code!
